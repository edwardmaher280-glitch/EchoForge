## 🚀 Quick Start (2 min)

### 1. Frontend (zero install)
Open `frontend/index.html` directly in your browser. It runs standalone.
- For dev: `npx serve frontend` or drag into browser.

### 2. Backend (Stripe)
```bash
cd backend
cp .env.example .env
# Edit .env with your Stripe test keys
npm install
npm run dev
# -> Backend on :4242 | SANDBOX MODE (if placeholder keys)
```

API:
- `POST /api/create-checkout-session` { plan: 'standard'|'pro'|'elite', email }
- `GET /api/verify-session?session_id=xxx`
- `GET /api/health`

**Sandbox mode**: If STRIPE_SECRET_KEY contains 'placeholder', no real Stripe call is made. It returns a fake checkout URL `/?checkout=success&plan=...` so you can test the full flow locally.

### 3. Production Stripe
1. Create products in Stripe Dashboard: Standard ($49), Pro ($149), Elite ($499)
2. Copy Price IDs: `price_...`
3. Fill `.env`:
```
STRIPE_SECRET_KEY=sk_live_...
STRIPE_PUBLISHABLE_KEY=pk_live_...
STRIPE_PRICE_STANDARD=price_1...
FRONTEND_URL=https://your-domain.com
```
4. Deploy backend to Fly.io / Render / Railway
5. Set `FRONTEND_URL` to your deployed frontend

### 4. Python Env (Research)
```bash
pip install gymnasium pandas numpy
python -c "from echoforge.envs.trading_env import EchoForgeTradingEnv; env = EchoForgeTradingEnv(); print('OK', env.reset())"
```

Train with SB3:
```python
from stable_baselines3 import PPO
env = EchoForgeTradingEnv()
model = PPO("MlpPolicy", env, verbose=1)
model.learn(100_000)
```

## 🧠 Architecture

**Frontend** — Dark fintech, agentic chat + portfolio + checkout. Uses `<frontend url>/?checkout=success` handshake with backend verification.

**Backend** — Minimal Express. No DB required for MVP. Stripe Checkout Sessions with metadata.plan. Webhook stub included.

**Env** — Transaction-cost aware, drawdown-penalized reward, synthetic fallback data if no CSV provided. Both Discrete and Continuous variants.

## 🔒 Security Notes
- Never commit `.env` (gitignored)
- Use `STRIPE_WEBHOOK_SECRET` in production to verify webhooks
- Frontend never sees secret key
